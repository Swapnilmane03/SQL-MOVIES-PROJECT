# 🎬 **Bollywood Movies Data Analysis – SQL Project**

This project analyzes a dataset of **Bollywood movies** using **SQL queries**.  
It explores insights about genres, actors, directors, budgets, revenues, profits/losses, and movie performance across multiple dimensions.

---

## 📊 Project Overview
The dataset contains details such as **movie name, genre, lead stars, directors, release period, budget, revenue, and number of screens**.  
Using SQL, I explored different business and entertainment-related questions, including:  

- Top movies by **budget, revenue, and screens**  
- Profit and loss analysis of Bollywood movies  
- Actor and director collaborations (e.g., *Akshay Kumar with Priyadarshan*)  
- Movies by specific stars (Aamir Khan, Salman Khan, Shahrukh Khan, Amitabh Bachchan, etc.)  
- Performance of movies across **genres** (Drama, Comedy, Thriller, etc.)  
- Hits vs. Flops and revenue-based ranking  
- Pattern-based queries (movies starting with “A”, ending with “a”, or starring “Khan”)  

---

## 🚀 Key SQL Queries
Some of the queries included are:
- Retrieve all **Drama genre** movies  
- Movies starring **Aamir Khan**  
- Movies directed by **Ram Gopal Verma**  
- Movies released on more than **1000 screens**  
- Movies with **Revenue > 700,000,000 INR**  
- Movies with **budget < 1 crore INR**  
- Identifying **flop movies** (Revenue < Budget)  
- Top **5 hit and flop movies** by profit/loss  
- Top **10 movies by revenue**  
- Movies starring **Akshay Kumar in Comedy genre**  
- Highest budget movies of **Amitabh Bachchan**  
- Biggest hit movie of **Shahrukh Khan** with director details
